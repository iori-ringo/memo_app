## 5. 改善優先度の提案

### 最優先

1. **本番ビルドで再計測する** — 開発サーバー（`next dev`）で計測されている可能性が高く、JS未圧縮・未使用JSの大部分はこれが原因。`next build && next start` した本番ビルドで再計測するとパフォーマンススコアは大幅に改善する可能性がある
2. **HTTP/2対応** — サーバー設定でHTTP/2を有効化（LCP改善に直結、1,430ms削減見込み）
3. **HTTPS化** — セキュリティ・ベストプラクティス両方に影響

### 次優先

4. **アクセシビリティ修正** — `<button>` に `aria-label` を付与、ページに `<main>` タグを追加
5. **レンダリングブロッキングCSS最適化** — Critical CSSのインライン化を検討
6. **bfcache対応** — 戻る/進む操作でのキャッシュ復元を有効化

### 備考

- 計測URLが `192.168.3.38:3000`（ローカルネットワーク）であるため、**開発環境での計測結果**と推定される
- Chrome拡張機能（`bubble_compiled.js`）が未使用JSの最大要因となっているため、シークレットモードでの再計測も推奨
